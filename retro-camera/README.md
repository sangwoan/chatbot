# 그날의 디카 (DX-2006)

옛날 디지털 카메라처럼 사진에 날짜와 촬영 정보를 찍어 주는 감성 카메라 웹앱(PWA)입니다.
「내가 당신을 사랑할 때 보이는 순간들」(빈티지 필름 카메라 앱, 감성 필터 8종 · 빛 · 색감 · 그레인 · 프레임)을 참고했습니다.

빌드 과정이나 의존성 없이 `index.html` 파일 하나로 동작하며, 폰 브라우저에서 열고 홈 화면에 추가하면 앱처럼 쓸 수 있습니다.

---

## 1. 기능

| 구분 | 내용 |
|---|---|
| 실시간 뷰파인더 | 후면/전면 카메라 전환, 필터와 스탬프가 적용된 화면을 미리 보여 줌 (WebGL) |
| 필터 8종 | ORIGINAL · CCD 디카 · WARM 200 · GREEN 400 · FADED '98 · DREAM · MONO · NIGHT 800, 필터 강도 0–100% |
| 날짜 스탬프 5종 | **FILM** 7세그먼트 오렌지 LED (`'26 10 10`) · **DIGI** 2000년대 디카 도트 글꼴 (`2026/10/10`) · **INFO** 사진 아래 정보 바 · **POLA** 폴라로이드 여백 + 손글씨 · **OFF** |
| 하단 정보 바 | 왼쪽: 문구(또는 `DX-2006 DIGITAL`) + 초점거리 · 조리개 · 셔터 · ISO / 오른쪽: 날짜 · 요일 · D-day · 위치 좌표 |
| 우리의 날 | 기념일을 넣으면 `D+412` 자동 계산 (그날 = D+1), 한 줄 문구 |
| 날짜 옵션 | 년월일 / 월일년 / 일월년 순서, 시간 표시, 날짜 직접 지정 |
| 촬영 | 셀프 타이머 3s/10s, 플래시(전면은 화면 플래시, 후면은 지원 기기에서 토치), 셔터음·AF 비프음(합성), 4:3 / 1:1, 2M·5M·8M |
| 앨범에서 가져오기 | 여러 장 한 번에 처리. **원본 EXIF의 촬영 날짜·조리개·셔터·ISO를 읽어** 그대로 찍어 줌 |
| 앨범 | 기기 브라우저(IndexedDB)에 보관, 재생 화면에서 저장 / 삭제 |
| 저장 | 모바일은 공유 시트(사진 앱에 저장), PC는 다운로드. 저장 파일에 EXIF 촬영일을 기록해 사진 앱에서 날짜순 정렬이 맞음 |
| 오프라인 | 서비스 워커로 앱 셸 캐시 |

## 2. 화면 설계

2006년 무렵 콤팩트 디카의 뒷면을 옮긴 구조입니다.

```
┌─────────────────────────────┐
│ ● 그날의 디카 DX-2006  [⚡][⏱][＋][≡] │  상단: 플래시 · 타이머 · 가져오기 · 메뉴
│ ┌─────────────────────────┐ │
│ │ AUTO CCD      5M [9993] ▮▮▮│ │  LCD: OSD(모드 · 화질 · 남은 매수 · 배터리)
│ │          ⌜   ⌝          │ │       AF 프레임, 좌우 스와이프 = 필터 변경
│ │          ⌞   ⌟          │ │
│ │               '26 10 10 │ │       스탬프 실시간 미리보기
│ └─────────────────────────┘ │
│  ◂ CCD │ WARM 200 │ GREEN ▸  │  모드 다이얼(가로 스크롤 스냅)
│ [FILM][DIGI][INFO][POLA][OFF]│  스탬프 선택
│ [앨범]      (  셔터  )  [전환]│
└─────────────────────────────┘
```

- MENU는 디카 메뉴 화면처럼 남색 패널 + 오렌지 선택 표시입니다.
- 촬영 후에는 디카의 재생 모드(`▶ 100-0012`) 화면에서 바로 저장하거나 지울 수 있습니다.
- 글꼴은 Silkscreen(OSD), IBM Plex Sans KR(UI·정보 바), Nanum Pen Script(폴라 손글씨)입니다.

## 3. 처리 흐름

```
카메라(getUserMedia) ─┐
앨범 사진 + EXIF ──────┼─▶ WebGL 셰이더(필터) ─▶ 2D 캔버스 합성 ─▶ 스탬프/프레임 ─▶ JPEG + EXIF ─▶ IndexedDB ─▶ 저장/공유
기본 카메라(input)  ───┘        (미리보기·촬영 동일)          (레이아웃: 사진 + 바/여백)
```

- **필터 셰이더 한 장**이 색수차 → 샤픈 → 블룸 → 노출 → 화이트밸런스 → 대비/채도 → 스플릿 톤 → 블랙 리프트 → 비네팅 → 그레인/컬러 노이즈를 처리합니다. 미리보기와 실제 촬영이 같은 코드를 쓰므로 보이는 대로 찍힙니다.
- WebGL이 없으면 캔버스 CSS 필터로 비슷하게 처리합니다.
- **FILM 스탬프**는 7세그먼트 숫자를 직접 그리고 빛 번짐(글로우)을 더해, 필름에 LED로 날짜를 노광하던 느낌을 냅니다. 그 시절 방식대로 숫자만 찍습니다.
- **DIGI 스탬프**는 5×7 도트 글꼴을 내장했습니다. 한글 문구는 작은 크기로 렌더링한 뒤 픽셀로 키워 같은 도트 느낌을 냅니다.
- 정보 바의 셔터·ISO는 실시간 카메라에서 실제 값을 얻을 수 없어 **화면 밝기로 계산한 감성 표기**입니다. 가져온 사진은 원본 EXIF 값을 그대로 씁니다.

### 필터 파라미터 요약

| 필터 | 성격 |
|---|---|
| CCD | 밝게, 파란 하이라이트, 강한 샤픈 + 디지털 컬러 노이즈, 약한 색수차 |
| WARM 200 | 따뜻한 화이트밸런스, 갈색 블랙, 그레인 |
| GREEN 400 | 초록 섀도, 낮은 채도, 굵은 그레인 |
| FADED '98 | 낮은 대비, 들뜬 블랙, 누런 색 빠짐 |
| DREAM | 핑크빛 블룸(넓은 반경), 부드러운 대비 |
| MONO | 흑백, 높은 대비, 굵은 그레인 |
| NIGHT 800 | 차가운 텅스텐 밸런스 + 하이라이트 주변 붉은 헐레이션 |

## 4. 실행 · 배포

카메라 API는 **HTTPS**(또는 localhost)에서만 켜집니다.

```bash
# PC에서 확인
cd retro-camera
python3 -m http.server 8000      # http://localhost:8000
```

폰에서 쓰려면 HTTPS로 올립니다. 가장 쉬운 방법은 GitHub Pages입니다.

1. 저장소 **Settings → Pages → Build and deployment**에서 Source를 `Deploy from a branch`로 두고 이 코드가 있는 브랜치와 `/ (root)`를 고릅니다.
2. 몇 분 뒤 `https://<계정>.github.io/<저장소>/retro-camera/`로 접속합니다. (비공개 저장소의 Pages는 GitHub 유료 플랜이 필요합니다.)
3. iPhone은 Safari 공유 → **홈 화면에 추가**, Android는 Chrome 메뉴 → **앱 설치**.

Netlify · Vercel · Cloudflare Pages에 `retro-camera` 폴더만 올려도 됩니다.

실시간 카메라를 쓸 수 없는 환경(HTTP 주소, 권한 거부, 일부 인앱 브라우저)에서는 샘플 화면으로 필터를 미리 보여 주고, 셔터를 누르면 휴대폰 기본 카메라가 열린 뒤 찍은 사진에 바로 스탬프를 찍습니다.

## 5. 한계와 다음 단계

- 사진은 **브라우저 저장소**에만 보관됩니다. 브라우저 데이터를 지우면 사라지므로 마음에 드는 사진은 저장해 두는 흐름입니다.
- iOS 웹앱은 사진 앱에 직접 쓸 수 없어 공유 시트의 「이미지 저장」을 거칩니다.
- 위치는 좌표만 표시합니다(주소 변환에는 외부 API 키가 필요).
- 네이티브 앱으로 옮긴다면(Capacitor로 감싸기 또는 Flutter/Swift로 재작성) 사진 앱 직접 저장, 실제 노출값, 줌/초점 제어, 동영상(캠코더 REC 오버레이)이 다음 후보입니다.
