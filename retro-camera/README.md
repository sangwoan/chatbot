# 그해여름

2001–2006년의 디지털 카메라 10대로 찍고, 그 시절처럼 사진에 날짜와 촬영 정보를 남기는 감성 카메라 웹앱(PWA)입니다.
카메라 종류마다 다른 색감을 입히는 구성은 「내가 당신을 사랑할 때 보이는 순간들」(빈티지 카메라 앱)을 참고했습니다.

빌드 과정이나 의존성 없이 `index.html` 파일 하나로 동작합니다. 폰 브라우저에서 열고 홈 화면에 추가하면 앱처럼 쓸 수 있습니다.

---

## 1. 카메라 10대

카메라를 고르면 색감, 화질, 노이즈, 앱의 바디 색, 정보 바의 기종명과 렌즈 값이 함께 바뀝니다. 기종명은 모두 가상의 이름입니다.

| 연도 | 기종 | 별명 | 화소 | 바디 | 찍히는 느낌 |
|---|---|---|---|---|---|
| 2001 | DIGI 130 | 첫 디카 | 1.3M CMOS | 플라스틱 그레이 | 자글자글한 컬러 노이즈, 색 뭉개짐, 과한 채도와 마젠타 기, 하이라이트 날아감 |
| 2002 | Q-2100 | 아빠 디카 | 2.0M CCD | 건메탈 | 부드러운 저화소, 가장자리 색수차와 보라색 번짐, 누르스름하고 차분한 색 |
| 2003 | DV-03 HANDYCAM | 캠코더 한 장 | 0.7M CCD | 네이비 | 비디오 가로줄, 옆으로 번지는 색, 빛 번짐, 들뜬 블랙 |
| 2004 | C-7 EASY | 골드 이지 | 4.0M CCD | 샴페인 골드 | 노란 햇살 색, 진한 채도, 따뜻한 인화 사진 톤 |
| 2004 | VGA FOLDER | 폴더폰 카메라 | 0.3M CMOS | 와인 레드 | 30만 화소 픽셀, 색 계단(밴딩), 초록 기, 강한 비네팅 |
| 2005 | IXA 55 | 은색 똑딱이 | 5.0M CCD | 실버 | 따뜻하고 자연스러운 피부, 선명한 빨강, 깔끔함 |
| 2005 | EX-S5 CARD | 카드 디카 | 5.0M CCD | 아이스 실버 | 밝게 날아간 하늘, 낮은 대비, 파스텔 |
| 2006 | T-77 SLIM | 핑크 슬림 | 7.2M CCD | 메탈릭 핑크 | 밝고 쨍한 화이트, 핑크빛 볼, CCD 특유의 또렷함 |
| 2006 | F-31 NIGHT | 밤의 디카 | 6.3M HR CCD | 피아노 블랙 | 깊은 청록 그림자, 차분한 대비, 밤빛 번짐 |
| 2006 | AQUA-720 | 방수 디카 | 7.1M CCD | 아쿠아 블루 | 시원한 청록 물빛, 높은 대비, 여름 바다 색 (기본 카메라) |

카메라를 고르는 방법은 세 가지입니다.

- 아래 다이얼을 넘기거나, 뷰파인더를 좌우로 쓸어 넘깁니다.
- 상단의 `그해여름 [AQUA ▾]`를 누르면 카메라 고르기 화면이 열립니다. 지금 장면이 10대로 각각 어떻게 찍히는지 미리 보여 줍니다.
- 다이얼에서 이미 선택된 카메라를 한 번 더 눌러도 같은 화면이 열립니다.

## 2. 그 밖의 기능

| 구분 | 내용 |
|---|---|
| 날짜 스탬프 5종 | **FILM** 7세그먼트 오렌지 LED (`'26 10 10`) · **DIGI** 2000년대 디카 도트 글꼴 (`2026/10/10`) · **INFO** 사진 아래 정보 바 · **POLA** 폴라로이드 여백과 손글씨 · **OFF** |
| 하단 정보 바 | 왼쪽: 문구(없으면 `AQUA-720 · 7.1M`)와 초점거리·조리개·셔터·ISO, 오른쪽: 날짜·요일·D-day·위치 좌표 |
| 우리의 날 | 기념일을 넣으면 `D+412`처럼 자동 계산 (그날 = D+1), 한 줄 문구 |
| 날짜 옵션 | 년월일 / 월일년 / 일월년 순서, 시간 표시, 날짜 직접 지정 |
| 촬영 | 셀프 타이머 3초/10초, 플래시(전면은 화면 플래시, 후면은 지원 기기에서 토치), 합성 셔터음·AF 비프음, 4:3 / 1:1, 저장 크기 2M·5M·8M, 필터 강도 |
| 앨범에서 가져오기 | 여러 장을 한 번에 처리하고, 원본 EXIF의 촬영 날짜·조리개·셔터·ISO를 그대로 찍어 줌 |
| 앨범·저장 | 기기 브라우저(IndexedDB)에 보관. 모바일은 공유 시트로 사진 앱에 저장, PC는 다운로드. 저장 파일의 EXIF에 촬영일과 기종명을 기록 |
| 오프라인 | 서비스 워커로 앱 셸 캐시 |

## 3. 화면 설계

```
┌─────────────────────────────┐
│ ● 그해여름 [AQUA▾]  [⚡][⏱][＋][≡] │  상단: 카메라 고르기 · 플래시 · 타이머 · 가져오기 · 메뉴
│ ┌─────────────────────────┐ │
│ │ AUTO AQUA-720  7.1M [9993]▮│ │  LCD: OSD(기종 · 화소 · 남은 매수 · 배터리)
│ │          ⌜   ⌝          │ │       좌우로 쓸어 넘기면 카메라 변경
│ │          ⌞   ⌟          │ │
│ │               '26 10 10 │ │       날짜 스탬프 실시간 미리보기
│ └─────────────────────────┘ │
│  ◂ T-77 │ F-31 │ AQUA ▸      │  카메라 다이얼 (2001 → 2006 순)
│ [FILM][DIGI][INFO][POLA][OFF]│  스탬프 선택
│ [앨범]      (  셔터  )  [전환]│
└─────────────────────────────┘
```

- 바디 색(금속 질감 그라데이션)과 각인 글자색이 카메라마다 바뀝니다. 버튼과 셔터는 공통 실버입니다.
- 카메라를 바꾸면 LCD에 `T-77 · 핑크 슬림 · 2006 · 7.2M CCD`와 그 카메라의 한 줄 이야기가 뜹니다.
- MENU는 디카 메뉴 화면처럼 남색 패널에 오렌지 선택 표시입니다. 촬영 후에는 재생 모드(`▶ 100-0012 AQUA`)에서 저장하거나 지울 수 있습니다.
- 글꼴은 Silkscreen(OSD), IBM Plex Sans KR(UI·정보 바), Nanum Pen Script(폴라 손글씨)를 씁니다.

## 4. 처리 흐름

```
카메라(getUserMedia) ─┐
앨범 사진 + EXIF ──────┼─▶ WebGL 셰이더(카메라 룩) ─▶ 2D 캔버스 합성 ─▶ 스탬프·프레임 ─▶ JPEG + EXIF ─▶ IndexedDB ─▶ 저장/공유
기본 카메라(input)  ───┘        (미리보기와 촬영이 같은 코드)
```

셰이더 하나가 아래 단계를 차례로 처리하고, 카메라마다 파라미터만 다릅니다.

1. **센서 해상도** `lowres`, `pixelate`: 30만·130만·200만 화소를 흉내 냅니다. 부드럽게 늘릴지, 픽셀이 보이게 늘릴지 정합니다.
2. **색 번짐** `chromaRes`, `smear`: 밝기는 원래 해상도로 두고 색만 거친 격자로 샘플링해 옛 JPEG처럼 색이 뭉개지게 합니다. 캠코더는 가로로만 번지게 합니다.
3. **렌즈** `ca`, `fringe`, `sharpen`: 색수차, 밝은 경계의 보라색 번짐, 디카 특유의 과한 샤프닝을 넣습니다.
4. **빛** `bloom`, `bloomTint`, `clip`: 빛 번짐(캠코더와 밤 카메라는 붉게)을 넣고, 하얗게 날아가는 하이라이트를 만듭니다.
5. **색** `exposure`, `gain`, `contrast`, `sat`, `shadowTint`, `highTint`, `black`: 노출, 화이트밸런스, 대비·채도, 스플릿 톤, 들뜬 블랙을 조정합니다.
6. **마무리** `vignette`, `grain`, `chroma`, `scan`, `poster`: 비네팅, 노이즈, 비디오 가로줄, 색 계단을 입힙니다.

WebGL이 없으면 카메라별 CSS 필터로 비슷하게 처리합니다.

그 밖의 처리 방식은 다음과 같습니다.

- **FILM 스탬프**: 7세그먼트 숫자를 직접 그리고 빛 번짐을 더했습니다. **DIGI 스탬프**: 5×7 도트 글꼴을 내장했고, 한글은 작게 렌더링한 뒤 픽셀로 키웁니다.
- **정보 바의 셔터·ISO**: 실시간 카메라에서는 실제 값을 얻을 수 없어 화면 밝기와 카메라 설정으로 계산한 감성 표기입니다. 가져온 사진은 원본 EXIF 값을 씁니다.

## 5. 실행 · 배포

카메라 API는 **HTTPS**(또는 localhost)에서만 켜집니다.

```bash
cd retro-camera
python3 -m http.server 8000      # http://localhost:8000
```

폰에서 쓰려면 HTTPS로 올립니다. 가장 쉬운 방법은 GitHub Pages입니다.

1. 저장소 **Settings → Pages → Build and deployment**에서 Source를 `Deploy from a branch`로 두고, 이 코드가 있는 브랜치와 `/ (root)`를 고릅니다.
2. 몇 분 뒤 `https://<계정>.github.io/<저장소>/retro-camera/`로 접속합니다. 비공개 저장소의 Pages는 GitHub 유료 플랜이 필요합니다.
3. iPhone은 Safari 공유 → **홈 화면에 추가**, Android는 Chrome 메뉴 → **앱 설치**를 누릅니다.

Netlify · Vercel · Cloudflare Pages에 `retro-camera` 폴더만 올려도 됩니다.

실시간 카메라를 쓸 수 없는 환경(HTTP 주소, 권한 거부, 일부 인앱 브라우저)에서는 샘플 화면으로 카메라 룩을 미리 보여 줍니다. 이때 셔터를 누르면 휴대폰 기본 카메라가 열리고, 찍은 사진에 바로 룩과 스탬프를 입힙니다.

## 6. 한계와 다음 단계

- 사진은 **브라우저 저장소**에만 보관됩니다. 브라우저 데이터를 지우면 사라지므로, 마음에 드는 사진은 저장해 두는 흐름입니다.
- iOS 웹앱은 사진 앱에 직접 쓸 수 없어 공유 시트의 「이미지 저장」을 거칩니다.
- 위치는 좌표만 표시합니다. 주소로 바꾸려면 외부 API 키가 필요합니다.
- 다음 후보는 카메라별 전용 스탬프(캠코더 `▶REC` 타임코드, 폴더폰 화면 프레임), 동영상, 네이티브 앱 전환(Capacitor 등)으로 사진 앱 직접 저장입니다.
